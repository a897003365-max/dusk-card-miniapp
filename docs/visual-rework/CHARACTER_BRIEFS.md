## 共用制作边界

- **已选方向**：用户已确认 `paper-courier` 纸灵驿使。以折纸结构、纸纤维和邮路工具统一材质，角色轮廓仍分别设计。
- **形体与材质**：下文的角、弧、分片、开口、关节描述几何结构；以纸张折面与纤维实现，同时为每位保留不同轮廓和职业工具。
- **保持亲切**：参考 v2 的短面部、可交流目光和适度头部比例；分别设计眼型和鼻口。禁止把所有脸替换成同一张美型面具，也不回到巨型玻璃珠眼、肉色婴儿脸和圆团短肢。

- **识别色不等于稀有度**：每位的底色长期稳定；R 青灰、SR 玉绿、SSR 紫、UR 金主要用于装裱与演出。四档共用同一身份的待机与施招图，以信印边框、光效和起手改造区分；旧 88 张收藏图留作历史原稿。
- **制作范围**：按已批准的三人样板扩展，每位制作待机、施招两张母稿，逐一检查身份、肢体与透明边缘后压缩接入。图内不烘焙名字、技能数字或 UI。

- **拒绝沿用**：奶油卷绒头罩、褐色圆脸、无颈绒球身体和贴腹短爪；不能把旧羊仅加角、换披风。

## 后续提示词的组合方式

每次制作只带入“当前已选材质 + 当前角色这一节 + 所需视角/动作 + 输出规格”。R 级先以轮廓和职责成立，再扩大到其他档位。不要把 22 节同时塞进一次生成请求，也不要先生成一个通用小人再批量换道具。

首轮检查先看无色剪影能否对应角色，再看缩至 64–96px 后脸和主工具是否清楚，最后看材质细节。若两位只剩颜色能区分，应返回形体设计；以上检查尚未在新角色图上执行，本文件不把文字设定当作已完成资产。
