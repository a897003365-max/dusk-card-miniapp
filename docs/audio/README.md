# 场景声音

本批包含 6 段原创短循环音乐和 16 条交互音效。2026-09-12 对 6 段音乐重新作曲配器，改用低中频木质拨弦、持续和声、柔和呼吸层、有休止的句子与段落变化，保留本机合成和手机播放链路。旋律、和声、噪声与音色均由本地脚本合成，没有使用现成歌曲或录音采样；新音频按 [CC0 1.0](./LICENSE.md) 提供，完整文件、时长及来源见 [资产台账](./ASSET_LEDGER.md)。

## 游戏中的开关

- 默认关闭音乐、开启音效。冒险、信匣、旅伴和来信页面顶部可以分别开关；战斗中打开右上角「记录」调整。
- 声音偏好保存在当前游戏存档键加 `-audio` 的独立位置。开关不修改伙伴、邮票、保底或战斗随机进度；保存偏好失败时，本次开关仍立即生效并提示。
- 切到后台停止全部声音；回前台恢复已开启的当前场景音乐。页面离开时清掉短音，不补播旧的战斗或揭晓反馈。
- 游戏声音开启后使用手机媒体音量，iOS 静音开关不再屏蔽它；关闭游戏声音即可静音。音乐音量为 32%，音效为 75%；最多一段音乐和两条短音同时播放。首次播放等待系统媒体设置成功。

## 配乐与反馈

| 场景 | 配乐 |
| --- | --- |
| 冒险城镇 | 80 BPM 六小节，木质拨弦主句、低音根音和稀疏长和声 |
| 信匣、旅伴与来信 | 80 BPM 六小节，留白较多的弦音、呼吸层和长音回答 |
| 黄昏邮街 | 80 BPM 八小节，旧街民谣式木拨弦，句尾留出休止 |
| 雨巷旧桥 | 80 BPM 八小节，D natural minor，低动态持续和声、细噪呼吸与稀疏漂浮句 |
| 夜行灯市 | 80 BPM 八小节，温和的木拨弦切分和低音行走 |
| Boss 战 | 约 68.6 BPM 四小节，A natural minor，低音持续、庄重木拨弦和缓慢张力 |

出牌与敌人行动按「施招、命中」两个节拍播放。护盾、治疗、增益、减益、洗牌、首领转阶段、奖励、胜负有相应声音，每个节拍选择一种主要反馈。胜利音改为 1.8s 的柔和木质邮戳起音与收束和弦，失败音改为 1.6s 的低音下行并留出停顿。声音发生在存档成功之后，音频加载失败不会改变或阻止战斗结算。

## 本地维护

```sh
node scripts/build-audio.js
npm test
node tests/claw-wxss.test.js --native
node scripts/check-package-budget.js
```

生成脚本只依赖 Node.js 和本机 `ffmpeg`，不会下载素材。WAV 母稿保留在 `masters/`；小程序打包只带 MP3，地区音乐随地区分包加载。

2026-09-12 重编后，本地检查覆盖脚本复建、WAV/MP3 解码、时长、单声道采样率、`ffmpeg volumedetect` 峰值和 WAV 首末循环边界。新的 6 首尚未由微信开发者工具 CLI 或手机完成播放验收；本地解码通过不代表手机听感或真机通过。

原生验收脚本 `tests/audio-runtime-smoke.js` 必须传隔离验收副本路径。`--region=street|bridge|market --allow-progress` 从真实已解锁入口实玩；`--draw --allow-progress` 消耗该副本的一张邮票验证启封音；`--keep-run` 在首次出牌与敌方回合之后保留本局。没有注入存档、余额或手牌的路径。

此前在开发者工具 2.02.2608040 中，CLI 能读取组件内部节点，但跨组件选择器的 `tap/trigger` 未能送达按钮事件。旧验收记录中的通过结论只对应旧音频版本；本次重编后的 CLI 验收由交付 Agent 单独执行，不能用旧记录替代。`--probe-assets` 为独立原生解码探针，不代表实际发生了首领战或稀有抽取。

主页面及战斗记录中提供「试听」，开启音效也会发出试听音。试听等待真实 onPlay 回调，错误或超时会显示提示；通话中断期间停止声音，结束后仅在前台恢复音乐。模拟器回调与解码不等同于手机听感，仍需重新扫码后实听确认。
