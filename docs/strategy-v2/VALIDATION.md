日期：2026-09-13。应用基线 main `1cef93f7c394c4422099973968f60b810f31a785`；接续分支基线 `501488e792936265101997bd98df418450f15f0b`。附带源码与远端应用树一致；不覆盖未随源码导出的历史 docs。

## 本次实现范围

保留九站、三人共享牌堆、12–16 张牌、现有费用/蓄能/久战规则及存档 KEY。没有新增伙伴、美术资源、第三方依赖或服务。多敌人遭遇与换牌机会只在黄昏邮街；奖励展示、构筑提示、战斗统计以及两张协同牌属于三地区共用逻辑。

1. 首场仍为单敌教学；后续六种遭遇模板提供单体厚甲、双敌分工、三只低血敌人、精英带随从。使用整场生命/主动伤害预算，不直接堆叠原怪物全额强度。敌方行动顺序、群攻、阶段转换、召唤和旧路线校验共用结算规则。
2. 营地与奇遇各有一次有限换牌。选择改造就放弃本节点其他收益；候选即时持久化，关闭/重开不重抽。三选一新通用牌，与一张非专属牌一进一出；保留原 UID、不继承升级、可选择归属。专属牌不可替换或转交。
3. 奖励改为构筑/功能/跨方向三个柔性加权槽，每次候选不重复、保留至少一张战术牌；不保证完美组合。通用奖励可在确认前选归属，实际数值随其等级与稀有度更新。构筑页说明费用、用途、四条思路及弱点，而非黑箱战力分。
4. 罗盘借星光、星毯铺平由仅自身改为可选择己方目标，原费用与数值不变；回响仍只重复下一张伤害牌首个伤害效果的一半。没有全队额外能量奖励。
5. 选牌预览展示实际伤害、击杀/转阶段、剩余资源及立即结束回合后的逐人掉血变化；调用真实结算的克隆，不写存档、不预知新抽牌。风险包含状态伤害、不是净生命变化；发现/观星尚待选择时不提供确定后续预测。回合按钮补上“本次结余转蓄”后的能量预估。状态超过两项显示 +N，详情保留全部状态。
6. 回执记录标记额外生命伤害、反击/灼烧实际伤害、留盾实际挡伤、释蓄、群体牌作用目标与转阶段清除的灼烧层数。旧战局从启用后才产生统计，会标记不完整，不虚构历史。
