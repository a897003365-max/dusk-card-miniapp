## 本轮发现与修复

- 原生运行时不能直接 `require` JSON 资产表；改为普通 CommonJS 模块，空白页问题已复验。
- 分包页的 `getWindowInfo` 返回旧标签页高度；触控验收改为当前渲染视口，并扣除实际底部安全区。
- 详情的末项查询不支持浏览器式 `:last-child`；工具先取得全部原生节点再选择末项，不放宽可见性断言。
- 自动化 getData 对 null 返回空对象；取消选择改用运行时 JSON 回读确认真实 null。
- 灼烧、回响伤害与状态施加原先可能混用飘字；生命事件增加明确 hpDelta，实际扣血显示负值。
- 培养档案和手牌使用引擎提供的当前效果描述；修复升级名称重复加号。放大关键数字，增加直接效果摘要，修正结算页顶栏跳位。
- 热更新后旧模块缓存曾让摘要为空；完整重新编译后已实际回读全部手牌摘要并截图。

中途失败报告原样保留于 `00-过程记录` 和相应阶段目录。自动化初始化超时属于未开始游戏动作的 CLI 启动失败，之后在就绪状态复跑成功，没有自动重试消费操作。
