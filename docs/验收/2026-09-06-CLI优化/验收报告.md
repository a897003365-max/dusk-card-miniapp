## CLI 运行方式

本机微信开发者工具 Stable `2.02.2608040`，基础库 `3.17.0`，`wechatide-skill` `0.3.9`。使用账号内可访问的独立测试号 `wx36c7c6b8b54e63c9`，未沿用原项目正式 AppID。

```sh
npm run devtools
node scripts/prepare-acceptance.js
node scripts/open-devtools.js <临时项目目录>
node tests/runtime-smoke.js <临时项目目录> --allow-progress
```

官方入口为 `/Applications/wechatwebdevtools.app/Contents/MacOS/cli auto` 与 `/Applications/wechatwebdevtools.app/Contents/MacOS/wechatide`。启动后以页面数据/真实节点可读确认就绪，实玩过程不反复编译。曾出现初始化超时，随后已接通；没有降低安全设置或修改认证信息。

脚本以至少 1300ms 调用间隔避开工具已有的 60 次/分钟限制。CLI 不接受旧 `--args` 参数，函数参数在 `--fn-source` 内明确编码；原生 SelectorQuery 按节点 dataset 匹配目标，不能把它当作支持所有浏览器属性选择器的查询器。

模型切换通过开发者工具界面选择，页面读取、点击、滚动、截图和断言均使用 CLI。所有消费发生在新建临时副本中，从正常初始存档起步，再使用剧情实际获得的邮票；没有清空真实存储或注入余额、卡牌。
