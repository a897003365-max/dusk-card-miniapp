# 手机声音、Boss 反馈与状态说明

本轮处理用户反馈：手机扫码预览听不到声音、Boss 单体/群体攻击识别不清、掉血反馈偏弱，以及需要详细状态说明。

## 本轮改动

- 音乐音量由 0.18 调整为 0.32，音效由 0.4 调整为 0.75。手机播放先等待 `setInnerAudioOption` 成功，再发声；使用媒体播放和扬声器，关闭 iOS 静音键对游戏音频的屏蔽。游戏内开关仍可关闭声音。
- 增加「试听」，开启音效也会发出试听音。只有收到原生 `onPlay` 才提示已播放；错误、取消和超时分别处理。通话中断及切后台会停声，恢复时不补播旧音效。
- 敌人依次施招、命中。Boss 有纸刃/纸风、墨击/墨浪、铃环/音浪三套几何特效；单体线指向真实目标坐标，群体波覆盖受影响小队，伤害/护盾/治疗分色显示。掉血数字增加纸色底片。
- 动画期间保留战斗画面和致命帧，但真实状态、奖励在动画前只提交一次。灼烧和新回合补牌单独分帧，避免把召唤物的灼烧误画成 Boss 攻击。
- 在「记录 → 状态说明」以及伙伴、敌人、卡牌详情加入统一说明。回响、标记、弱化、灼烧、反击、留盾各有触发规则、叠加/消耗时机、例子与提示；单位入口展示实际当前值，卡牌入口优先打开相关状态。倍率常量由计算、卡面和说明共享，玩法数值没有改变。

手机音频策略依据 [微信官方 API 类型说明](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)：`obeyMuteSwitch=false` 作用于 iOS 静音模式；`speakerOn=true` 会采用扬声器策略，可能与其他音频互斥。没有修改手机系统音量或本机系统音量。

## 模型分工与边界

Luna max 负责复杂战斗反馈的首轮实现；主代理负责手机音频、状态说明、整合与原生验收；Sol high 做有界只读复核。复核发现的灼烧/补牌归属问题已修正，并以真实 resolver 回归测试和复核确认。

实战、消费和录像只在独立测试号 `wx36c7c6b8b54e63c9` 的隔离副本 `dusk-card-acceptance-nyMDCE` 中进行。状态说明检查只读。录像仅捕获绑定的微信开发者工具窗口，不含音轨或麦克风，因此录像只能证明画面效果。

**手机实际听感仍待重新扫码确认。** 模拟器的播放回调不能证明手机扬声器已发声，旧二维码不会自动获得本次代码。当前尚未为本轮上传新预览或发布；生成新手机预览需遵循项目对上传的授权要求。正式源码窗口的历史 SDK 启动问题见上一轮报告，本轮运行验证以代码一致的隔离副本为准。
