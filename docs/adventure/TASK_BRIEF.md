# 冒险副本任务简报

用户已批准《晚霞来信》冒险副本扩展方案：3人手动出牌、10–15分钟、3套旧街巷童话副本、22伙伴、62牌、18遗物、21敌人；低稀有度可策略通关，失败轻惩罚。

交付是可玩的原生微信小程序、可编辑源码和本土化2.5D素材。原有88张公仔收藏图是角色身份参考，不是要放大的最终战斗图。保留轮廓/面部/标志配饰，增加东方邮路职业与环境。画面必须服务点牌、选目标、看意图与读反馈。

用户明确批准生成角色、敌人、插画及分层背景。图像来源按本地角色参考→可明确使用的素材→经批准的原创生成；代码只制作界面、标识与动画，不代替角色插画。没有真实3D模型交付。

美术先提供水彩街巷/纸艺灯影/绒偶微缩三种真实方向样板，用户选定之后再扩展整套角色和副本资源。当前方向未选定，不把方案批准当作最终像素批准。其他已授权代码与战斗内容并行推进。

母稿、提示词和资产来源存docs/adventure，运行图复制进项目。界面文字/数值不烘焙到背景。照片式素材不是事实证据；设计是虚构世界创作。

验收包括普通R队伍通关、至少3构筑、存档迁移/断点/奖励原子性、320/390/430原生CLI与独立视觉复核。初版只在隔离副本消耗测试资源，不上传发布。
